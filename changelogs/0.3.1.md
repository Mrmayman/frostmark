# 0.3.1

## Added

- Table support
  - HTML `<table>`, `<thead>`, `<tbody>`, `<tfoot>`
  - Markdown tables (with alignment)
- Ruby rendering
  - `<ruby>`, `<rb>`, `<rt>`, `<rp>`, `<rtc>`

## Changed

- Allow starting `<ol>` (lists) with custom start value
  (thanks [@mariinkys](https://github.com/mariinkys))
- Fixed some edge-case issues in `<details>` and `<summary>`
